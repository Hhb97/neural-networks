1 极限与连续

进阶

初学者指南里，我们把极限理解成"无限靠近但不一定到达"。这一节把这句直觉翻译成一句可以逐字检验、不依赖"感觉"的数学陈述——ε-δ 语言。它的好处是：任何人都可以拿到具体的 ε，独立算出一个 δ，然后机械地验证极限是否成立，不再需要"看图说话"。

1.1 极限的 ε-δ 定义

定义（极限） 设函数 \(f\) 在 \(a\) 的某个去心邻域内有定义。称 \[ \lim_{x \to a} f(x) = L \] 当且仅当：对任意 \(\varepsilon > 0\)，都存在 \(\delta > 0\)，使得只要 \(0 < |x-a| < \delta\)，就有 \(|f(x) - L| < \varepsilon\)。

逐字翻译一遍：无论对方（挑剔的验证者）给出多小的容差 \(\varepsilon\)（"你敢说 \(f(x)\) 和 \(L\) 差不超过这个数吗？"），我们都必须能给出一个对应的 \(\delta\)，使得只要 \(x\) 与 \(a\) 的距离小于 \(\delta\)（但不等于 0），\(f(x)\) 与 \(L\) 的距离就确实小于 \(\varepsilon\)。这是一场"你出 ε 我出 δ"的博弈，我们必须每次都能赢。

1.2 一个完整的 ε-δ 证明

用一个线性传感器响应模型做例子：设某电压传感器的输出模型为 \(f(x) = 2x+1\)（\(x\) 是原始 ADC 读数，\(f(x)\) 是标定后的电压值，单位省略）。下面严格证明 \(\lim_{x\to 3} f(x) = 7\)。

证明 任给 \(\varepsilon > 0\)，取 \(\delta = \varepsilon/2\)。当 \(0 < |x-3| < \delta\) 时： \[ |f(x) - 7| = |(2x+1) - 7| = |2x - 6| = 2|x-3| < 2\delta = 2 \cdot \frac{\varepsilon}{2} = \varepsilon \] 于是对任意 \(\varepsilon>0\)，取 \(\delta=\varepsilon/2\) 即可满足定义要求，故 \(\lim_{x\to 3}(2x+1) = 7\)。
∎

代入具体数字核验：取 \(\varepsilon = 0.02\)，按证明中的取法 \(\delta = \varepsilon/2 = 0.01\)。取 \(x = 3.005\)（满足 \(|x-3|=0.005<0.01\)），则 \(f(x) = 2\times3.005+1 = 7.01\)，\(|f(x)-7| = 0.01 < 0.02\)，与证明吻合。这个 \(\delta=\varepsilon/2\) 的关系正是因为 \(f\) 的斜率是 2——斜率越大，为了控制住 \(f(x)\) 的波动，\(\delta\) 就必须选得越小。

1.3 连续的 ε-δ 刻画

把定义里"\(x\) 不等于 \(a\)"这条限制去掉，并要求逼近的目标恰好就是 \(f(a)\)，就得到连续的严格定义：对任意 \(\varepsilon>0\)，存在 \(\delta>0\)，使得 \(|x-a|<\delta \Rightarrow |f(x)-f(a)|<\varepsilon\)。这与初学者指南 1.3 节的 \(\lim_{x\to a}f(x)=f(a)\) 完全等价，只是把"极限"本身也展开成了 ε-δ 的形式。

💡 为什么要较真到这个程度？ 深度学习里常说"损失函数是连续甚至光滑的，所以梯度下降才有效"——这句话之所以严谨可靠，靠的正是这里的 ε-δ 定义：它保证了参数的微小扰动，只会引起损失的微小、可控的变化，而不会突然跳变。
🔍 ε-δ 交互演示：\(f(x)=2x+1\)，\(a=3,\ L=7\)
ε = 0.40 δ = 0.15
拖动两个滑块：蓝色竖直虚线是 \(x=3\pm\delta\) 的范围，橙色水平虚线是 \(y=7\pm\varepsilon\) 的范围。只要 δ-邻域内的曲线段完全落在 ε-邻域内，下方就会显示"✅ 满足"；由于斜率是 2，理论上只要 \(\delta \le \varepsilon/2\) 就必定满足。

2 导数与微分

进阶

初学者指南把导数定义为"平均变化率的极限"。这一节要问一个更深的问题：如果只知道区间两端点的平均变化率，能对区间内部的瞬时变化率说些什么？答案是中值定理（Mean Value Theorem, MVT）——微分学里最重要的定理之一，后面 FTC 的证明也要靠它。

2.1 拉格朗日中值定理

定理（拉格朗日中值定理，MVT） 若函数 \(f\) 在闭区间 \([a,b]\) 上连续，在开区间 \((a,b)\) 内可导，则存在至少一点 \(c \in (a,b)\)，使得 \[ f'(c) = \frac{f(b)-f(a)}{b-a} \]

直白地说：无论一个函数在区间端点之间怎么"抖动"，只要它连续且处处可导，就一定存在某个内部时刻，瞬时变化率恰好等于整段区间的平均变化率——不可能整个过程都严格快于平均，也不可能整个过程都严格慢于平均。

2.2 深入例子：设备累计能耗曲线

示例数据（用于演示计算，非实际记录） 设某 IoT 电能记录仪对一台设备的累计能耗建立了如下拟合模型：\(E(t) = 0.2t^2 + 1.5t\)（\(t\)：运行时长，单位小时；\(E\)：累计能耗，单位 kWh）。按小时采样得到：

运行时长 \(t\)（h）123456
累计能耗 \(E(t)\)（kWh）1.73.86.39.212.516.2

先计算区间 \([1,6]\) 上的平均能耗变化率（即两端点连线——割线——的斜率）：

\[ \frac{E(6)-E(1)}{6-1} = \frac{16.2 - 1.7}{5} = \frac{14.5}{5} = 2.9 \ \text{kWh/h} \]

\(E(t)\) 是多项式函数，在 \([1,6]\) 上连续、在 \((1,6)\) 内处处可导，满足 MVT 的条件。故存在 \(c\in(1,6)\) 使 \(E'(c)=2.9\)。求导得 \(E'(t) = 0.4t+1.5\)，令其等于 2.9：

\[ 0.4c + 1.5 = 2.9 \ \Rightarrow\ 0.4c = 1.4 \ \Rightarrow\ c = 3.5 \]

验证：\(c=3.5\) 确实落在 \((1,6)\) 内。这说明在 \(t=3.5\) 小时这一瞬间，设备的瞬时耗电速率恰好等于整个 5 小时区间的平均耗电速率——这不是巧合，是 MVT 保证一定存在这样的时刻。

💡 MVT 也是后面第 6 节证明微积分基本定理的关键工具：把"累积量的变化"和"瞬时速率"重新联系起来，靠的正是"平均值一定在某处被瞬时达到"这个事实。

3 求导法则

进阶

初学者指南直接给出了四则运算求导公式。这一节把乘法和除法的求导公式从极限定义严格推导出来，并给出链式法则成立所需要的精确条件——这个条件在后面第 9、10 节讨论反向传播时会重新出现。

3.1 乘法法则的推导

设 \(u(x)\)、\(v(x)\) 都在 \(x\) 处可导。按定义：

\[ (uv)'(x) = \lim_{h\to 0} \frac{u(x+h)v(x+h) - u(x)v(x)}{h} \]

关键技巧是在分子中加、减同一项 \(u(x+h)v(x)\)（凑出两个可以分别处理的差）：

\[ \begin{aligned} &\phantom{=} u(x+h)v(x+h) - u(x)v(x) \\ &= u(x+h)v(x+h) - u(x+h)v(x) + u(x+h)v(x) - u(x)v(x) \\ &= u(x+h)\big[v(x+h)-v(x)\big] + \big[u(x+h)-u(x)\big]v(x) \end{aligned} \]

两边除以 \(h\) 再取极限，并利用 \(u\) 在 \(x\) 处可导必连续（故 \(u(x+h)\to u(x)\)）：

\[ (uv)'(x) = u(x)\cdot v'(x) + u'(x)\cdot v(x) \]

除法法则可以用同样手法对 \(u/v\) 展开，或者把 \(u/v\) 写成 \(u \cdot v^{-1}\) 再结合乘法法则和链式法则得到，这里不重复展开，结论仍是初学者指南给出的 \(\left(\frac{u}{v}\right)' = \frac{u'v-uv'}{v^2}\)（\(v(x)\neq 0\)）。

3.2 链式法则的精确条件

定理（链式法则） 设 \(g\) 在 \(x_0\) 处可导，\(f\) 在 \(g(x_0)\) 处可导，则复合函数 \(f\circ g\) 在 \(x_0\) 处可导，且 \[ (f\circ g)'(x_0) = f'(g(x_0)) \cdot g'(x_0) \]

要点是：链式法则不是"总成立"的万能公式，它需要内层函数在这一点可导，且外层函数在内层的取值处也可导这两个条件同时满足。神经网络里如果某一层用了不可导的激活函数（比如 ReLU 在 0 点），从数学上讲那一点的链式法则并不严格成立，工程上是靠人为规定次梯度（例如令 ReLU 在 0 处的"导数"取 0 或 1）来绕过这个问题的。

3.3 深入例子：功率对时间的变化率

示例数据（用于演示计算，非实际记录） 设备启动阶段，电压、电流随时间（\(t\)：分钟）近似线性变化：\(V(t) = 220 + 0.5t\)（V），\(I(t) = 5 - 0.02t\)（A）。瞬时功率 \(P(t) = V(t)I(t)\)，用乘法法则直接求导：

\[ P'(t) = V'(t)I(t) + V(t)I'(t) = 0.5\cdot I(t) + V(t)\cdot(-0.02) \]

在 \(t=0\) 处代入：\(P'(0) = 0.5\times 5 + 220\times(-0.02) = 2.5 - 4.4 = -1.9\) W/min。

直接展开验证：把 \(P(t)\) 完全展开：

\[ P(t) = (220+0.5t)(5-0.02t) = 1100 - 4.4t + 2.5t - 0.01t^2 = 1100 - 1.9t - 0.01t^2 \]

直接求导：\(P'(t) = -1.9 - 0.02t\)，在 \(t=0\) 处同样得到 \(-1.9\)——与乘法法则算出的结果完全一致。这说明设备刚启动时，尽管电压在缓慢上升，功率却在下降，原因是电流下降的效应（\(-4.4\)）超过了电压上升的效应（\(+2.5\)）。

⚙️ 乘法法则演示：\(P(t)=V(t)I(t)\) 及其两种求导方式的一致性
t = 0.0 乘法法则 P' = -1.90 直接展开 P' = -1.90
蓝色曲线是功率 \(P(t)\)，橙色曲线是它的导数 \(P'(t)\)（两种算法给出的曲线完全重合）。可以看到功率先降后可能回升的走势由电压、电流两个相反效应共同决定。

4 高阶导数与泰勒展开

进阶

初学者指南只演示了"阶数越高、近似越准"这个现象。这一节补上关键的一环：泰勒展开只取有限项时，到底差多少？这个"差多少"有一个可以精确写出、甚至可以提前估计上界的表达式——拉格朗日余项。

4.1 带拉格朗日余项的泰勒定理

定理（泰勒定理，拉格朗日余项形式） 设 \(f\) 在包含 \(a\) 的区间上具有直到 \(n+1\) 阶的连续导数，则对该区间内任意 \(x\)，存在介于 \(a\) 与 \(x\) 之间的 \(\xi\)，使得 \[ f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!}(x-a)^k \;+\; \underbrace{\frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1}}_{R_n(x)\ \text{（余项）}} \]

这个定理最大的价值在于：即使不知道 \(\xi\) 具体是哪一点，只要能对 \(|f^{(n+1)}|\) 在整个区间上找到一个上界 \(M\)，就能给出余项的确定性上界 \(|R_n(x)| \le \dfrac{M}{(n+1)!}|x-a|^{n+1}\)——不需要知道真实值，也能保证近似误差不超过多少。

4.2 深入例子：传感器标定曲线的线性近似

示例数据（用于演示计算，非实际记录） 某电流传感器的原始 ADC 读数 \(x\) 与标定后电压值之间，近似满足非线性标定曲线 \(f(x)=\sqrt{x}\)。工程上常用"在某个工作点附近做线性近似"来快速估算附近读数对应的电压，而不必每次都开方。取工作点 \(a=100\)（此时 \(f(100)=10\)）：

\[ f'(x) = \frac{1}{2\sqrt{x}},\quad f'(100)=\frac{1}{20}=0.05, \qquad f''(x) = -\frac{1}{4x^{3/2}},\quad f''(100) = -0.00025 \]

一阶（线性）近似：\(f(100+\Delta x) \approx 10 + 0.05\,\Delta x\)。取 \(\Delta x = 4\)（即读数 \(x=104\)）：

\[ f(104) \approx 10 + 0.05\times 4 = 10.2 \]

真实值 \(\sqrt{104} = 10.198039\ldots\)，误差 \(\approx 0.001961\)。用拉格朗日余项估计这个误差的上界：由于 \(|f''(x)|=\frac{1}{4x^{3/2}}\) 在 \([100,104]\) 上单调递减，最大值在左端点取得，即 \(|f''(\xi)| \le |f''(100)| = 0.00025\)，于是

\[ |R_1| \le \frac{0.00025}{2!}\times 4^2 = \frac{0.00025}{2}\times 16 = 0.002 \]

实际误差 \(0.001961 \le 0.002\)，理论上界成立，且贴得很紧。下表列出了 \(x=100\) 附近几个读数的标定曲线示例数据、线性近似值与误差：

5 积分基础

进阶

初学者指南把定积分直接理解为"曲线下方的面积"。这一节要问：这个"面积"到底是怎么被定义出来的？答案不是靠几何直觉，而是靠一个严格的极限过程——黎曼和的极限。

5.1 黎曼积分的严格定义

定义（黎曼积分） 将 \([a,b]\) 等分为 \(n\) 份，\(\Delta x = \frac{b-a}{n}\)，取每个小区间的一个代表点 \(x_i^*\)（例如右端点），构造黎曼和 \[ S_n = \sum_{i=1}^{n} f(x_i^*)\,\Delta x \] 若当 \(n\to\infty\)（\(\Delta x \to 0\)）时 \(S_n\) 收敛到一个与代表点选取方式无关的确定值，就称这个极限为 \(f\) 在 \([a,b]\) 上的定积分： \[ \int_a^b f(x)\,dx = \lim_{n\to\infty} S_n \]

这比"求面积"严格得多：它把"面积"归约成了一个纯粹的数列极限问题，不再依赖几何直觉，因而也能推广到根本不是"面积"的场合（比如概率密度的积分、高维体积）。

5.2 深入例子：精确计算一个黎曼和的极限

示例数据（用于演示计算，非实际记录） 延续第 2 节的设备能耗模型：瞬时功率（能耗速率）为 \(P(t) = 0.4t+1.5\)（kW），想知道从 \(t=0\) 到 \(t=6\) 小时的累计能耗。直接构造右端点黎曼和：\(\Delta x = 6/n\)，\(t_i = 6i/n\)：

\[ S_n = \sum_{i=1}^{n} P(t_i)\,\Delta x = \sum_{i=1}^{n}\left(0.4\cdot\frac{6i}{n}+1.5\right)\frac{6}{n} = \frac{6}{n}\left[\frac{2.4}{n}\sum_{i=1}^n i + 1.5n\right] \]

代入 \(\sum_{i=1}^n i = \frac{n(n+1)}{2}\)：

\[ S_n = \frac{6}{n}\left[\frac{2.4}{n}\cdot\frac{n(n+1)}{2} + 1.5n\right] = \frac{6}{n}\big[1.2(n+1) + 1.5n\big] = \frac{6}{n}\big[2.7n + 1.2\big] = 16.2 + \frac{7.2}{n} \]

这是一个精确的闭式表达式（不是数值近似）：当 \(n\to\infty\) 时，\(\frac{7.2}{n}\to 0\)，故

\[ \int_0^6 (0.4t+1.5)\,dt = \lim_{n\to\infty} S_n = 16.2 \]

用不定积分核对：\(\int_0^6(0.4t+1.5)dt = [0.2t^2+1.5t]_0^6 = 0.2\times36+1.5\times6 = 7.2+9=16.2\)，与黎曼和的精确极限完全一致——这正是设备 6 小时累计的总能耗，与第 2 节能耗模型 \(E(6)=16.2\) kWh 相符（因为 \(P=E'\)，这一点第 6 节会正式说明）。

6 微积分基本定理

进阶

初学者指南展示了 FTC 成立的现象。这一节给出完整的证明骨架——它并不需要什么新工具，只需要把第 2 节的中值定理和第 5 节的黎曼积分定义组合起来。

6.1 微积分基本定理（第一部分）与证明

定理（FTC 第一部分） 若 \(f\) 在 \([a,b]\) 上连续，定义 \(F(x) = \int_a^x f(t)\,dt\)，则 \(F\) 在 \((a,b)\) 内可导，且 \(F'(x) = f(x)\)。
证明骨架 按导数定义，考察差商： \[ \frac{F(x+h)-F(x)}{h} = \frac{1}{h}\int_x^{x+h} f(t)\,dt \] 由积分中值定理（MVT 在积分上的推广版本：\(f\) 连续时，\(\int_x^{x+h}f(t)dt = f(\xi)\cdot h\) 对某个 \(\xi\) 介于 \(x\) 与 \(x+h\) 之间成立），上式等于 \(f(\xi)\)。当 \(h\to 0\) 时，\(\xi\) 被夹在 \(x\) 与 \(x+h\) 之间，必然 \(\xi \to x\)；又因为 \(f\) 连续，\(f(\xi)\to f(x)\)。故 \[ F'(x) = \lim_{h\to 0}\frac{F(x+h)-F(x)}{h} = \lim_{h\to 0} f(\xi) = f(x) \]
∎

再看它的推论——牛顿-莱布尼茨公式：若 \(F' = f\)，则 \(\int_a^b f(x)dx = F(b)-F(a)\)。这个推论直接由"\(F(x)-\int_a^x f(t)dt\) 的导数恒为 0，故它是常数"再代入 \(x=a\) 求出这个常数即可得到。

6.2 深入例子：从功率到能耗，再验证回功率

示例数据（用于演示计算，非实际记录） 沿用第 2、5 节的设备模型：瞬时功率 \(P(t)=0.4t+1.5\)（kW），累计能耗 \(E(t)=\int_0^t P(s)\,ds\)。直接积分：

\[ E(t) = \int_0^t (0.4s+1.5)\,ds = \big[0.2s^2+1.5s\big]_0^t = 0.2t^2+1.5t \]

这正是第 2 节一开始给出的能耗模型 \(E(t)=0.2t^2+1.5t\)——原来它就是功率曲线 \(P(t)\) 的累积。按 FTC，反过来对 \(E(t)\) 求导应该精确地还原出 \(P(t)\)：

\[ E'(t) = 0.4t + 1.5 = P(t) \]

两者逐点相等（对任意 \(t\) 都成立，不只是某个特定点），这就是 FTC 在这个具体例子上的完整验证：先积分（功率→能耗）再求导（能耗→功率），精确地回到了出发点。

P(t) = 2.30 E'(t) = 2.30
拖动滑块，观察 \(E(t)\) 曲线在该点切线的斜率始终精确等于当前 \(P(t)\) 的值——这就是 \(E'(t)=P(t)\) 的直观呈现。

7 多元函数与偏导数

进阶

初学者指南说"偏导数就是固定其他变量、只对一个变量求导"。这一节要指出一个很多人会忽略、但极其重要的陷阱：所有偏导数都存在，并不能保证函数是"可微"的。这两者是不同的概念，下面用一个经典反例把差距具体展示出来。

7.1 多元可微性的精确定义

定义（可微） 函数 \(f(x,y)\) 在点 \((a,b)\) 处可微，是指存在向量 \((A,B)\)（若可微，则必有 \(A=\partial f/\partial x,\ B=\partial f/\partial y\)），使得 \[ f(a+h,b+k) = f(a,b) + Ah + Bk + o\!\left(\sqrt{h^2+k^2}\right), \quad (h,k)\to(0,0) \] 其中 \(o(\cdot)\) 表示这一项相对于 \(\sqrt{h^2+k^2}\) 是高阶小量，即 \(\lim_{(h,k)\to(0,0)} \frac{o(\sqrt{h^2+k^2})}{\sqrt{h^2+k^2}} = 0\)。

直觉上，"可微"要求函数在这一点附近能被一个平面（而不只是两条独立的直线）很好地逼近——这比"沿 x 轴方向、沿 y 轴方向分别可导"严格得多，因为它还要求所有斜方向都能被同一个平面协调地逼近。

7.2 经典反例：偏导数存在但不可微（甚至不连续）

考虑函数：

\[ f(x,y) = \begin{cases} \dfrac{xy}{x^2+y^2}, & (x,y)\neq(0,0) \\ 0, & (x,y)=(0,0)\end{cases} \]

偏导数在原点确实存在：\(\frac{\partial f}{\partial x}(0,0) = \lim_{h\to0}\frac{f(h,0)-f(0,0)}{h} = \lim_{h\to0}\frac{0-0}{h}=0\)（因为 \(f(h,0)=\frac{h\times0}{h^2}=0\)）。同理 \(\frac{\partial f}{\partial y}(0,0)=0\)。两个偏导数都存在且等于 0。

但函数在原点并不连续：沿任意一条经过原点、方向角为 \(\theta\) 的直线趋近原点（即 \(x=t\cos\theta,\ y=t\sin\theta,\ t\to0\)），代入化简：

\[ f(t\cos\theta, t\sin\theta) = \frac{t^2\cos\theta\sin\theta}{t^2(\cos^2\theta+\sin^2\theta)} = \cos\theta\sin\theta = \frac12\sin(2\theta) \]

这个值与 \(t\) 无关，只与方向角 \(\theta\) 有关！沿 \(\theta=45°\) 方向趋近时极限是 \(\frac12\)，沿 \(\theta=0°\)（x 轴）趋近时极限是 \(0\)。不同方向趋近给出不同的极限值，说明 \(\lim_{(x,y)\to(0,0)}f(x,y)\) 根本不存在，函数在原点不连续。而可微必然蕴含连续，所以这个函数在原点不可微——尽管它的两个偏导数都老老实实地存在。这正是"偏导数存在 ≠ 可微"最直接的证据。

💡 工程含义： 在实现自定义神经网络层时，如果只检查了"对每个参数单独求导都有值"就断定这一层处处可微，是不够的——真正安全的做法是确认函数在感兴趣区域内是 \(C^1\)（偏导数存在且连续），这是一个能推出可微的、更容易验证的充分条件。

7.3 梯度与最速上升方向（预告）

当函数确实可微时，把各个偏导数按顺序排成向量就得到梯度 \(\nabla f\)。利用柯西-施瓦茨不等式可以证明梯度方向就是函数值增长最快的方向——完整证明和数值演示放在下一节（8.2）里，与方向导数的形式化定义一起给出。

7.4 深入例子：单神经元损失对参数的偏导数

示例数据（用于演示计算，非实际记录） 设一个最简单的线性神经元，用归一化后的电压 \(x_1\)、电流 \(x_2\) 预测归一化能耗 \(y\)：

样本电压 \(x_1\)（归一化）电流 \(x_2\)（归一化）实际能耗 \(y\)（归一化）
样本 A231

模型 \(\hat y = w_1x_1 + w_2x_2 + b\)，当前参数 \(w_1=0.5,\ w_2=-0.2,\ b=0.1\)。损失取平方误差的一半 \(L=\frac12(\hat y-y)^2\)（这个 \(\frac12\) 只是为了让求导后系数更干净）。

前向计算：

\[ \hat y = 0.5\times2 + (-0.2)\times3 + 0.1 = 1.0 - 0.6 + 0.1 = 0.5, \qquad L = \frac12(0.5-1)^2 = \frac12\times0.25 = 0.125 \]

偏导数（多元函数 \(L(w_1,w_2,b)\) 对各参数的偏导数）：把 \(x_2,b\) 固定不变、只令 \(w_1\) 变化，用链式法则（\(L\) 是 \(\hat y\) 的函数，\(\hat y\) 是 \(w_1\) 的函数）：

\[ \frac{\partial L}{\partial w_1} = \frac{\partial L}{\partial \hat y}\cdot\frac{\partial \hat y}{\partial w_1} = (\hat y - y)\cdot x_1 = (0.5-1)\times2 = -1.0 \]

同理：

\[ \frac{\partial L}{\partial w_2} = (\hat y-y)\cdot x_2 = -0.5\times3 = -1.5, \qquad \frac{\partial L}{\partial b} = (\hat y-y)\cdot 1 = -0.5 \]

这三个偏导数将在第 8 节被拼成梯度向量 \(\nabla L = (-1.0,\,-1.5,\,-0.5)\)，并用来判断"往哪个方向调整参数，损失下降最快"。

🧩 反例可视化：不同方向趋近原点时 \(f(t\cos\theta,t\sin\theta)\) 的极限值
横轴是趋近方向角 \(\theta\)，纵轴是沿该方向趋近原点时 \(f\) 收敛到的值 \(\frac12\sin(2\theta)\)。它不是一条水平线——说明不同方向给出不同极限，函数在原点没有统一的极限（不连续），即使沿 \(\theta=0°\) 和 \(\theta=90°\)（对应两个偏导数）取值恰好都是 0。

8 梯度与方向导数

进阶

初学者指南直接断言"梯度方向是上升最快的方向"。这一节把方向导数写成严格定义，并用柯西-施瓦茨不等式完整证明这个断言，然后在第 7 节的神经元例子上验证一遍数字。

8.1 方向导数的严格定义

定义（方向导数） 设 \(\mathbf{u}=(u_1,u_2)\) 是单位向量（\(\|\mathbf u\|=1\)）。函数 \(f\) 在点 \(\mathbf{p}\) 处沿方向 \(\mathbf u\) 的方向导数定义为 \[ D_{\mathbf u}f(\mathbf p) = \lim_{t\to 0}\frac{f(\mathbf p + t\mathbf u) - f(\mathbf p)}{t} \] 若 \(f\) 在 \(\mathbf p\) 处可微，可以证明 \(D_{\mathbf u}f(\mathbf p) = \nabla f(\mathbf p)\cdot \mathbf u\)。

（这条"若可微则方向导数等于梯度点乘方向"的结论，正是 7.2 节反例失效的地方——那个函数不可微，所以它的方向导数 \(\frac12\sin2\theta\) 无法写成任何固定向量 \(\mathbf g\) 与 \(\mathbf u=(\cos\theta,\sin\theta)\) 的点积 \(\mathbf g\cdot\mathbf u = g_1\cos\theta+g_2\sin\theta\)——因为后者只能是单一频率的正弦曲线，而 \(\sin2\theta\) 是双倍频率。）

8.2 梯度是最速上升方向：柯西-施瓦茨证明

证明 对任意单位向量 \(\mathbf u\)，由柯西-施瓦茨不等式： \[ D_{\mathbf u}f = \nabla f\cdot \mathbf u \le \|\nabla f\|\,\|\mathbf u\| = \|\nabla f\| \] 等号成立当且仅当 \(\mathbf u\) 与 \(\nabla f\) 方向相同，即 \(\mathbf u = \dfrac{\nabla f}{\|\nabla f\|}\)。此时 \(D_{\mathbf u}f = \|\nabla f\|\)，是所有方向中能取到的最大值。故梯度方向就是函数值增长最快的方向，其反方向（负梯度）就是下降最快的方向。
∎

8.3 深入例子：验证第 7 节神经元的最速方向

示例数据（用于演示计算，非实际记录） 沿用 7.4 节的梯度 \(\nabla L = (\partial L/\partial w_1,\ \partial L/\partial w_2) = (-1.0,\,-1.5)\)（这里只看 \(w_1,w_2\) 两个方向，暂不看 \(b\)）。梯度的模长：

\[ \|\nabla L\| = \sqrt{(-1.0)^2+(-1.5)^2} = \sqrt{1+2.25} = \sqrt{3.25} \approx 1.802776 \]

最速上升方向的单位向量：

\[ \mathbf u^* = \frac{\nabla L}{\|\nabla L\|} \approx (-0.554700,\ -0.832050) \]

沿这个方向的方向导数应精确等于 \(\|\nabla L\|\)。直接代入验证：

\[ D_{\mathbf u^*}L = \nabla L\cdot \mathbf u^* = (-1.0)(-0.554700) + (-1.5)(-0.832050) = 0.554700+1.248075 = 1.802775 \]

（末位的 0.000001 误差来自四舍五入）与 \(\|\nabla L\|\) 完全吻合。再对比另一个方向，例如 \(\mathbf u=(1,0)\)（只调 \(w_1\)）：\(D_{(1,0)}L = -1.0\)，明显小于 \(1.802776\)——说明只沿单个坐标轴方向调整，不如沿梯度方向调整下降（或上升）得快，这正是梯度下降沿负梯度整体方向而不是"每次只调一个参数"的原因。

🧭 方向导数 vs. 角度：与 7 节反例的鲜明对比
这条曲线是 \(D_{\mathbf u}L(\theta) = -1.0\cos\theta - 1.5\sin\theta\)，是单一频率的正弦曲线（可以写成 \(\|\nabla L\|\cos(\theta-\varphi)\) 的形式），峰值恰好出现在梯度方向角处，峰值高度正好是 \(\|\nabla L\|\approx1.8028\)。与 7 节反例中双倍频率、无法写成这种形式的 \(\frac12\sin2\theta\) 形成对照——这正是"可微"与"不可微"在方向导数图像上的直接区别。

9 链式法则与自动微分

进阶

初学者指南给出了多元链式法则的公式和计算图的直觉图示。这一节补上两件事：多元链式法则的证明思路，以及反向传播为什么在计算复杂度上远胜"暴力对每个参数分别求导"的前向模式——这是自动微分能撑起千万参数模型的根本原因。

9.1 多元链式法则的证明思路

设 \(z=f(u,v)\)，\(u=g(x,y)\)，\(v=h(x,y)\)，且 \(f,g,h\) 都可微。利用 7.1 节可微性的定义展开 \(z\) 关于 \(x\) 的微小扰动 \(\Delta x\)（保持 \(y\) 不变）：\(u\) 的变化量 \(\Delta u = \frac{\partial u}{\partial x}\Delta x + o(\Delta x)\)，\(v\) 的变化量同理。再把这两个变化量代入 \(z=f(u,v)\) 的可微性展开式：

\[ \Delta z = \frac{\partial f}{\partial u}\Delta u + \frac{\partial f}{\partial v}\Delta v + o(\sqrt{\Delta u^2+\Delta v^2}) \]

把 \(\Delta u,\Delta v\) 的展开式代入并整理高阶小量项（因为 \(g,h\) 可微，\(\Delta u,\Delta v\) 本身是 \(\Delta x\) 的一阶量，所以那些 \(o(\cdot)\) 项在除以 \(\Delta x\) 后仍趋于 0），两边除以 \(\Delta x\) 并令 \(\Delta x\to0\)，就得到初学者指南 9.1 节给出的公式：

\[ \frac{\partial z}{\partial x} = \frac{\partial z}{\partial u}\frac{\partial u}{\partial x} + \frac{\partial z}{\partial v}\frac{\partial v}{\partial x} \]

这个推导也说明了为什么链式法则需要每一环都可微：只有可微性提供的"线性近似 + 高阶小量可忽略"这个结构，才能保证上面凑高阶小量的步骤真正成立。

9.2 用第 7 节的例子验证链式法则

回顾 7.4 节：\(\hat y = w_1x_1+w_2x_2+b\)，\(L=\frac12(\hat y-y)^2\)。链式法则说 \(\frac{\partial L}{\partial w_1}=\frac{\partial L}{\partial \hat y}\cdot\frac{\partial \hat y}{\partial w_1}\)。分别算出两段：\(\frac{\partial L}{\partial \hat y}=\hat y-y=0.5-1=-0.5\)，\(\frac{\partial \hat y}{\partial w_1}=x_1=2\)。相乘：

\[ \frac{\partial L}{\partial w_1} = (-0.5)\times 2 = -1.0 \]

与 7.4 节直接算出的 \(-1.0\) 完全一致——链式法则"分段算、再相乘"给出的结果，和把 \(L\) 写成 \(w_1\) 的显式函数直接求导，得到的是同一个数。

9.3 前向模式 vs. 反向模式：复杂度权衡

自动微分沿着计算图传播导数信息有两种方式：前向模式从输入出发，随着前向计算同步传播"每个中间量对某一个固定输入的导数"；反向模式（也就是反向传播）从输出出发，反向传播"损失对每个中间量的导数"。两者的计算代价有本质区别：

  • 若函数有 \(n\) 个输入、\(m\) 个输出，前向模式每一遍只能求出"全部输出对一个输入"的导数（雅可比矩阵的一列），要得到完整的梯度信息需要跑 \(n\) 遍。
  • 反向模式每一遍只能求出"一个输出对全部输入"的导数（雅可比矩阵的一行），要得到完整信息需要跑 \(m\) 遍。

神经网络训练中，参数个数 \(n\) 可能有数百万甚至上亿，而损失函数的输出 \(m\) 永远是 1（一个标量）。所以反向模式只需要一次反向传播就能拿到损失对每一个参数的梯度，而前向模式理论上需要对每个参数各跑一遍、共 \(n\) 遍——这就是为什么 PyTorch、TensorFlow 的自动微分（autograd）都以反向模式为核心实现的根本原因。

💡 反向模式的代价是需要在前向计算时缓存下所有中间结果（用于反向时计算局部导数），这带来了额外的内存开销——这正是显存往往成为训练大模型瓶颈的原因之一。
⚖️ 前向模式 vs. 反向模式：达到完整梯度所需的传播遍数
n = 500
损失函数的输出恒为 \(m=1\)。前向模式所需遍数随参数个数线性增长（灰色柱），反向模式恒为 1 遍（紫色柱）——参数越多，反向模式的优势就越夸张，这正是深度学习必须依赖反向传播的现实原因。

10 MLP 应用 —— 反向传播

进阶

初学者指南给出了一次前向传播的数值例子。这一节补上完整的反向传播——对一个真实的两层网络，手工算出损失对每一个权重的梯度，做几步真正的梯度下降，并验证损失确实在下降。

10.1 网络结构与示例数据

示例数据（用于演示计算，非实际记录） 用归一化后的电压 \(x_1\)、电流 \(x_2\) 预测归一化能耗 \(y\)，网络结构为 \(2 \to 2(\text{ReLU}) \to 1\)：

样本电压 \(x_1\)电流 \(x_2\)实际能耗 \(y\)
样本 B121.5

初始参数：

\[ W^{[1]} = \begin{bmatrix}0.3 & -0.1\\ 0.2 & 0.4\end{bmatrix}, \quad \mathbf b^{[1]} = \begin{bmatrix}0.1\\-0.2\end{bmatrix}, \qquad W^{[2]} = \begin{bmatrix}0.5 & -0.3\end{bmatrix}, \quad b^{[2]} = 0.05 \]

10.2 前向传播（逐步数值计算）

\[ \mathbf z^{[1]} = W^{[1]}\mathbf x + \mathbf b^{[1]} = \begin{bmatrix}0.3\times1 -0.1\times2 + 0.1\\ 0.2\times1+0.4\times2-0.2\end{bmatrix} = \begin{bmatrix}0.2\\0.8\end{bmatrix} \]

经过 ReLU（两个分量都为正，ReLU 不改变数值）：\(\mathbf a^{[1]} = \text{ReLU}(\mathbf z^{[1]}) = (0.2,\ 0.8)\)。

\[ \hat y = W^{[2]}\mathbf a^{[1]} + b^{[2]} = 0.5\times0.2 + (-0.3)\times0.8 + 0.05 = 0.1 - 0.24 + 0.05 = -0.09 \]

损失（平方误差的一半）：

\[ L = \frac12(\hat y-y)^2 = \frac12(-0.09-1.5)^2 = \frac12\times(1.59)^2 = \frac12\times2.5281 = 1.26405 \]

10.3 反向传播（逐层手算全部梯度）

输出层误差项：

\[ \delta^{[2]} = \frac{\partial L}{\partial \hat y} = \hat y - y = -0.09-1.5 = -1.59 \]

输出层权重、偏置的梯度：

\[ \frac{\partial L}{\partial W^{[2]}_1} = \delta^{[2]}\cdot a^{[1]}_1 = -1.59\times0.2 = -0.318, \quad \frac{\partial L}{\partial W^{[2]}_2} = \delta^{[2]}\cdot a^{[1]}_2 = -1.59\times0.8 = -1.272 \] \[ \frac{\partial L}{\partial b^{[2]}} = \delta^{[2]} = -1.59 \]

反向传播到隐藏层：先把误差沿 \(W^{[2]}\) 传回去，再逐元素乘上 ReLU 的导数（两个 \(z^{[1]}\) 分量都 \(>0\)，故 \(\text{ReLU}'=1\)）：

\[ \frac{\partial L}{\partial a^{[1]}_1} = \delta^{[2]}\cdot W^{[2]}_1 = -1.59\times0.5=-0.795, \quad \frac{\partial L}{\partial a^{[1]}_2} = \delta^{[2]}\cdot W^{[2]}_2 = -1.59\times(-0.3)=0.477 \] \[ \delta^{[1]}_1 = -0.795\times1 = -0.795, \qquad \delta^{[1]}_2 = 0.477\times1 = 0.477 \]

第一层权重、偏置的梯度：

\[ \frac{\partial L}{\partial W^{[1]}_{11}} = \delta^{[1]}_1 x_1 = -0.795, \quad \frac{\partial L}{\partial W^{[1]}_{12}} = \delta^{[1]}_1 x_2 = -1.59, \quad \frac{\partial L}{\partial b^{[1]}_1} = \delta^{[1]}_1 = -0.795 \] \[ \frac{\partial L}{\partial W^{[1]}_{21}} = \delta^{[1]}_2 x_1 = 0.477, \quad \frac{\partial L}{\partial W^{[1]}_{22}} = \delta^{[1]}_2 x_2 = 0.954, \quad \frac{\partial L}{\partial b^{[1]}_2} = \delta^{[1]}_2 = 0.477 \]

至此，损失对全部 9 个参数（6 个第一层权重、2 个第一层偏置、2 个第二层权重、1 个第二层偏置——共 9 个数值）的梯度都已算出。

10.4 梯度下降更新一步，验证损失下降

取学习率 \(\eta=0.05\)，按 \(w \leftarrow w-\eta\frac{\partial L}{\partial w}\) 更新全部参数，例如：

\[ W^{[2]}_1 \leftarrow 0.5 - 0.05\times(-0.318) = 0.5159, \qquad b^{[2]} \leftarrow 0.05 - 0.05\times(-1.59) = 0.1295 \]

其余参数按同样方式更新后为：\(W^{[1]}=\begin{bmatrix}0.33975 & -0.02050\\0.17615 & 0.35230\end{bmatrix}\)，\(\mathbf b^{[1]}=(0.13975,\,-0.22385)\)，\(W^{[2]}=(0.5159,\,-0.2364)\)。用新参数重新做一次前向传播：

\[ \mathbf z^{[1]}_{\text{new}} = (0.4385,\ 0.6569), \quad \mathbf a^{[1]}_{\text{new}} = (0.4385,\ 0.6569) \] \[ \hat y_{\text{new}} = 0.5159\times0.4385 + (-0.2364)\times0.6569 + 0.1295 \approx 0.20043 \] \[ L_{\text{new}} = \frac12(0.20043-1.5)^2 \approx 0.84444 \]

损失从 \(1.26405\) 降到了 \(0.84444\)——仅仅一步梯度下降，损失就下降了约 33%。这正是梯度下降"沿负梯度方向走一小步、损失必定（在学习率合适时）下降"这一理论保证的真实数值体现，其数学依据正是第 4 节的线性近似：\(L(\mathbf w-\eta\nabla L)\approx L(\mathbf w) - \eta\|\nabla L\|^2 < L(\mathbf w)\)（只要 \(\eta\) 不太大、梯度不为零）。

🎯 收敛性： 反复重复"前向传播 → 反向传播求梯度 → 按学习率更新参数"这一循环，损失会持续下降；下方演示区用同一组样本数据实际跑了这个循环（并非凭空模拟的示意曲线），可以看到损失从 1.26 一路下降、逐渐逼近 0——因为该样本本身可以被这个网络精确拟合。真实训练中，损失通常不会精确到 0（受限于数据噪声、模型容量、正则化等），但"沿负梯度方向持续下降直到梯度接近 0（收敛到驻点）"的机制是完全一样的。

10.5 十章回顾

  • 第 1 节的 ε-δ 定义保证了损失函数的连续性是可以严格验证的；

  • 第 9 节的多元链式法则与反向模式复杂度分析，正是本节能够一次反向传播算出全部 9 个梯度的根本原因。
